# World Car Sales Data Analyzer

A C++ program to read and analyze world car sales data from a CSV file.

## Overview

This project provides a simple CSV reader class in C++ that parses car sales data and organizes it into structured data for analysis. The program reads a CSV file containing 1 million rows of car sales records from around the world.

## Features

- **CSV Parsing**: Reads CSV files with headers and parses each row into a map for easy access.
- **Structured Data**: Stores data in vectors and maps for programmatic analysis.
- **Performance**: Supports loading a limited number of rows to handle large files efficiently.
- **Multithreaded Parsing**: Uses multiple threads for fast loading of large datasets.
- **Data Analysis**: Provides specific analysis functions for car sales data, including:
  - Counting sales by manufacturer, country, and year.
  - Calculating total revenue by manufacturer and year.
  - Revenue distribution by country for specific regions and manufacturers.

## Analysis Capabilities

The program includes built-in analysis for the following problem statements based on the dataset:

1. **Audi Sales in China (2025)**: Determines the number of cars sold by Audi in China during 2025.
2. **BMW Total Revenue (2025)**: Calculates the total revenue generated by BMW in 2025.
3. **BMW Revenue Distribution in Europe**: Provides revenue distribution across European countries for BMW, sorted from highest to lowest.

These analyses are performed efficiently on the loaded dataset without requiring external tools.

## CSV File Details

The program expects a CSV file named `world_car_sales_1m.csv` in the same directory. This file contains approximately 1 million rows of car sales data.

### CSV Structure

The CSV has the following columns (headers):

- `sale_id`: Unique identifier for each sale
- `sale_date`: Date of the sale (YYYY-MM-DD format)
- `country`: Country where the sale occurred
- `region`: Geographic region (e.g., Asia, North America, Europe)
- `latitude`: Latitude coordinate of the dealership
- `longitude`: Longitude coordinate of the dealership
- `dealership_id`: Unique ID for the dealership
- `dealership_name`: Name of the dealership
- `manufacturer`: Car manufacturer (e.g., Subaru, Skoda, MG)
- `model`: Car model (e.g., Impreza, Octavia, 3)
- `vehicle_year`: Year the vehicle was manufactured
- `body_type`: Type of vehicle body (e.g., Hatchback, Sedan, SUV, Convertible)
- `fuel_type`: Fuel type (e.g., Diesel, Petrol, CNG)
- `transmission`: Transmission type (e.g., Automatic, Manual, CVT)
- `drivetrain`: Drivetrain configuration (e.g., RWD, AWD, FWD)
- `color`: Vehicle color
- `vin`: Vehicle Identification Number
- `condition`: Vehicle condition (New or Used)
- `previous_owners`: Number of previous owners
- `odometer_km`: Mileage in kilometers
- `sale_price_usd`: Sale price in USD
- `currency`: Original currency of the sale
- `financing`: Whether financing was used (True/False)
- `payment_type`: Payment method (Cash, Loan, etc.)
- `sales_channel`: How the sale was made (In-store, etc.)
- `buyer_id`: Unique buyer identifier
- `buyer_age`: Age of the buyer
- `buyer_gender`: Gender of the buyer
- `buyer_income_usd`: Buyer's annual income in USD
- `salesperson_id`: Unique salesperson identifier
- `salesperson_name`: Name of the salesperson
- `warranty_months`: Warranty period in months
- `warranty_provider`: Warranty provider (Dealer or other)
- `features`: Additional features (e.g., Backup Camera;Android Auto;Adaptive Cruise)
- `co2_g_km`: CO2 emissions in grams per kilometer
- `mpg_city`: Miles per gallon (city)
- `mpg_highway`: Miles per gallon (highway)
- `engine_displacement_l`: Engine displacement in liters
- `horsepower`: Engine horsepower
- `torque_nm`: Engine torque in Newton-meters
- `dealer_rating`: Dealership rating
- `condition_notes`: Notes about vehicle condition
- `service_history`: Whether service history is available (True/False)

## Prerequisites

- C++ compiler (e.g., g++ on Linux/Mac, or clang++ on Mac)
- Standard C++ libraries (included with compiler)

## Building and Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mohityada/WorldCarSales.git
   cd WorldCarSales
   ```

2. **Obtain the CSV file**: Place `world_car_sales_1m.csv` in the project directory.

3. **Compile the program**:
   ```bash
   g++ Driver.cpp -o Driver
   ```

4. **Run the program**:
   ```bash
   ./Driver
   ```

The program will load the first 10 rows of data (for performance), print the headers, number of loaded rows, and details of the first row.

## Code Structure

- `CsvReader.h`: Header file containing the `CsvReader` class for parsing CSV files.
- `Driver.cpp`: Main program that uses `CsvReader` to load and display data.
- `RevenueService.h`: (If present) Additional service for revenue analysis.

## Modifying Row Limit

To load more rows, edit `Driver.cpp` and change the second argument in `openAndReadCsv("world_car_sales_1m.csv", 10)` to a higher number (e.g., 1000). Be cautious with large numbers as it may consume significant memory and time.
